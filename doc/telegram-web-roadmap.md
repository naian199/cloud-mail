# Telegram Web 风格交互

目标是让站内聊天、群组和频道使用一致的聊天交互，站外邮件继续遵守正常邮件收发规则。参考 Telegram Web 的交互，不使用 Telegram 的品牌、账号体系或服务器。

## 1.3.0 已实现

- 私聊消息右键或长按菜单进入多选，点击消息或复选框增减选择；最多 100 条。
- 复制选中的文字，顺序与时间线一致。底部操作栏替换输入区，取消或 Escape 退出。
- 批量仅自己删除；全为站内消息时可双方删除。确认后逐条处理，失败时保留尚未删除的选择以便重试。切换会话后停止提交剩余操作，已提交的请求仍可能完成。此操作不是数据库事务。
- 图片和视频统一全屏查看器，支持上一项/下一项、左右键、Escape 和下载原件。视频控件获得焦点时，左右键仍用于原生播放进度控制。打开大图会暂停会话中的视频，关闭后不自动恢复播放。
- 媒体列表覆盖当前已加载的会话消息；加载更早历史可扩展。附件沿用登录验证，不公开存储地址。
- 粘贴图片和文件到聊天输入区加入附件草稿，不自动发送；与拖放、选择文件共用数量和大小限制。
- 群组/频道在已加载消息中搜索并跳转匹配结果；成员管理按昵称/用户名筛选。现有邀请、管理员权限、频道只读规则和未读通知保留。

## 1.3.2 媒体预览

可见视频在浏览器内从受登录保护的附件生成 JPEG 封面，并读取真实比例及播放时长，不会自动播放或上传封面。历史视频无需重新发送。最多两个预览任务并发处理；离开可见区域取消未完成读取/解码，切换会话释放封面地址。生成过程中显示加载状态，浏览器不支持解码时保留播放、兼容处理和原件下载，不自动进行完整转码。

图片按原始比例缩放，纯图片/视频去掉厚气泡留白及文件名底栏，点击仍可打开媒体查看器。

## 1.4.0 导航与会话列表

主导航改为默认关闭的覆盖式抽屉，旧版“常驻展开”偏好不再使用；点击左上角菜单打开，点击遮罩、返回按钮或 Escape 关闭，选择菜单入口后自动收起。搜索下方提供站内聊天、站外邮件、群聊与频道四类入口。原 `/rooms` 和带 `room` 的深链接继续可用，选中的频道会激活频道分类。

抽屉内的收件箱、已发送、草稿箱及星标邮件放在邮件分组；个人设置和管理放在底部，账号、主题和退出入口保留。管理入口仍由权限控制。

桌面会话列表默认 300px，拖动右边界可调至 260–420px，偏好保存在当前浏览器并在聊天、站外邮件、群组和频道之间共用。聚焦分隔线可用左右键调整、Shift 加速、Home/End 到最小/最大值；双击恢复 300px。手机不显示分隔线，列表和正文分别使用整屏。右到左界面按相应方向调整宽度。

## 1.5.0 综合搜索

搜索框不再放置加号。聚焦空搜索可进入新会话、联系人、新建群组或频道、设置，多个可用邮箱时也能切换搜索邮箱。输入关键词后按联系人、公开用户名、会话、群组/频道、邮件消息、群内消息分组。支持正文、备注、邮箱及附件文件名；正文结果包含命中位置附近的摘要，点击可定位历史消息。用户名沿用现有至少 3 字符的前缀搜索规则，不公开陌生用户邮箱。

邮件范围是界面明确显示的当前邮箱；群组名称限本人已加入或受邀的群组/频道，群内正文仅限已加入的群组/频道。搜索不会索引陌生私密群组、其他人的邮箱、已删除邮件或已删除的引用正文。大结果集提供分页；历史邮件尚未整理完毕时显示状态并继续索引。输入节流 300ms，换词、换邮箱或离开页面会取消过期读取，防止迟到结果覆盖当前查询。
