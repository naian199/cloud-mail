# Telegram Web 风格交互

目标是让站内聊天、群组和频道使用一致的聊天交互，站外邮件继续遵守正常邮件收发规则。参考 Telegram Web 的交互，不使用 Telegram 的品牌、账号体系或服务器。

## 1.3.0 已实现

- 私聊消息右键或长按菜单进入多选，点击消息或复选框增减选择；最多 100 条。
- 复制选中的文字，顺序与时间线一致。底部操作栏替换输入区，取消或 Escape 退出。
- 批量仅自己删除；全为站内消息时可双方删除。确认后逐条处理，失败时保留尚未删除的选择以便重试。切换会话后停止提交剩余操作，已提交的请求仍可能完成。此操作不是数据库事务。
- 图片和视频统一全屏查看器，支持上一项/下一项、左右键、Escape 和下载原件。视频控件获得焦点时，左右键仍用于原生播放进度控制。打开大图会暂停会话中的视频，关闭后不自动恢复播放。
- 媒体列表覆盖当前已加载的会话消息；加载更早历史可扩展。附件沿用登录验证，不公开存储地址。
- 粘贴图片和文件到聊天输入区加入附件草稿，不自动发送；与拖放、选择文件共用数量和大小限制。
- 群组/频道在已加载消息中搜索并跳转匹配结果；成员管理按昵称/用户名筛选。现有邀请、管理员权限、频道只读规则和未读通知保留。

## 1.3.2 媒体预览

可见视频在浏览器内从受登录保护的附件生成 JPEG 封面，并读取真实比例及播放时长，不会自动播放或上传封面。历史视频无需重新发送。最多两个预览任务并发处理；离开可见区域取消未完成读取/解码，切换会话释放封面地址。生成过程中显示加载状态，浏览器不支持解码时保留播放、兼容处理和原件下载，不自动进行完整转码。

图片按原始比例缩放，纯图片/视频去掉厚气泡留白及文件名底栏，点击仍可打开媒体查看器。
