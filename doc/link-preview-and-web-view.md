# 网页预览与站内浏览（1.19.0）

聊天中的文字链接和预览卡片默认打开站内网页浏览窗口，提供原始链接、重新加载、关闭以及“浏览器打开”。Ctrl/Command 点击、右键和手机长按仍使用真实链接。相同站点的应用链接保持普通链接行为，避免嵌套打开邮箱自身。

预览支持 Open Graph、Twitter Card 和 JSON-LD 标题、摘要与封面。预览读取不执行网页脚本、不携带用户登录信息；登录限制、反爬验证、缺少元数据或网络失败都可能导致没有摘要。此时明确显示“暂未获取到网页摘要”，并提供重试。成功预览缓存 5 分钟，失败结果缓存 30 秒；缓存始终在邮件或群组访问校验之后使用。

站内窗口使用原网站的隔离 iframe，不是独立浏览器引擎。网站的 CSP 或 X-Frame-Options 可以禁止嵌入；需要 Cookie、存储或登录的网站也可能无法在隔离窗口使用，点击“浏览器打开”即可。HTTP 链接不尝试混合内容嵌入。等待超过 10 秒提供外部打开提示，原页面仍可继续加载。

工具栏始终显示原始链接；网页端无法可靠读取跨站跳转后的地址，因此不提供虚假的地址栏或前进、后退状态。窗口不获得邮箱访问令牌，不授予网页相机、麦克风、定位、支付或剪贴板权限。关闭窗口或切换应用页面会移除嵌入页。
