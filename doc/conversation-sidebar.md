# 可收起会话列表（1.22.0）

电脑端搜索框右侧的独立箭头可以在完整列表和 64px 窄栏之间切换。左上角三横线仍然打开网站导航。

窄栏保留分类图标、联系人头像或群组首字、选中状态和未读数。悬停头像可查看完整名称与未读数，键盘也能访问这些会话。联系人原有的右键菜单和排序不变。更多会话使用省略号入口继续加载，列表仍可用滚轮或键盘滚动。

点击窄栏的搜索图标会展开列表并聚焦万能搜索；收起时会关闭搜索结果，避免隐藏搜索状态让头像消失。切换不会关闭当前聊天，也不会清空正在编辑的草稿。

浏览器记住收起状态，原有展开宽度单独保留，不会把 64px 写入宽度偏好。展开后可继续使用原有 260–420px 拖动及键盘宽度调整。四个会话分类共用此偏好。

紧凑手机布局忽略收起偏好，保持完整列表与聊天页面切换；回到电脑宽度后恢复偏好。该功能不修改聊天数据、未读规则、网站域名或服务端设置。
