# 安装到桌面和手机主屏幕

版本：1.10.0。

网站支持以 PWA 形式添加到桌面或手机主屏幕，并在独立应用窗口打开，启动地址为 `/mail-chat`。安装后仍需联网访问邮箱，邮件数据和账号权限沿用现有网站，不把私人 API、邮件页面缓存为离线页面。

## 使用入口

支持原生安装提示的浏览器会显示可关闭的小提示卡，点击“立即安装”后由浏览器确认安装。只在用户点击时打开安装窗口，不把用户接受提示直接当作安装成功，接收 `appinstalled` 后才更新安装状态。

关闭提示后 7 天内不再自动提醒。左侧导航底部仍保留安装入口，可以随时再次查看操作方法。在已安装的独立应用窗口内不显示提示。输入文字时隐藏自动提示卡，避免遮挡输入区。

- Chrome、Edge：使用页面按钮，或地址栏及浏览器菜单的安装入口。
- iPhone/iPad：浏览器“分享”→“添加到主屏幕”→“添加”；缺少选项时用 Safari 打开网站。
- Android：浏览器菜单中的“安装应用”或“添加到主屏幕”。
- 支持的 macOS Safari：文件→添加到程序坞。

具体选项由浏览器和系统版本决定。应用安装不会自动开启通知权限；通知继续遵循原有个人设置与浏览器授权。

## 配置与验证

清单固定应用身份 `id: /`、作用域 `/`，显示模式为 `standalone`；使用既有 192px 邮箱图标和包含同一图标的可缩放 SVG，不改变现有品牌图标。iOS 使用 `/mail-pwa.png` 作为主屏幕图标。

本地持久浏览器配置的 Chromium 安装资格与清单检查无错误；浏览器自动化覆盖安装事件、关闭后保留偏好、iOS 指引和独立窗口不重复提示。安装确认窗口使用浏览器事件模拟，手机系统实际添加操作仍由用户完成。线上发布会额外校验清单、图标和 Service Worker 可读取。
