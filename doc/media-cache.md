# 视频加载与本地缓存

版本：1.9.0。

视频预览原先需要在每次挂载组件时重新下载附件，再用浏览器解码生成封面。现在优先读取本地封面，已下载的视频也可在会话内、切换后、刷新后、全屏和下载原文件时复用。

## 范围和容量

- IndexedDB 保留最多 7 天，全部媒体记录合计上限 96 MB、120 条，超出后淘汰旧记录。
- 单个原视频最多缓存 20 MB；封面最多 512 KB。内存缓存单独限制为 32 MB、40 条。
- 大于 8 MB 的视频不为生成预览自动下载。点击播放后才读取原文件，并从已解码画面保存封面。
- 第一次加载仍需要网络和解码。缓存已被浏览器清理、文件超限或更换浏览器、设备及网站域名时，需要重新读取。
- IndexedDB 不可用时回退到当前页面内存缓存；不把完整视频塞进 localStorage。

## 权限与生命周期

缓存只从当前已获授权的消息附件元数据建立，键区分用户、邮箱、附件 ID、文件名、大小和 MIME，不存储登录令牌。不改变服务端附件授权和 `private, no-store` 响应头，也不把私人附件放入公共 CDN 或 Service Worker 公共缓存。

退出登录、登录失效进入登录页或其他标签页更换令牌时，清空媒体缓存并取消未完成读取。清空过程中已经过期的请求不会重新写回缓存。各组件自己的 Blob URL 仍在卸载时释放。

同一视频的多个视图共用一次附件读取。取消一个视图只取消该订阅，其他视图仍可完成；全部视图取消时中止原请求。

## 验证

单元测试覆盖缓存身份隔离、有效期、清空、并发合并及中止。浏览器实测首次预览后，切换会话、刷新、播放、全屏和下载不增加附件请求，退出登录后 IndexedDB 记录为零；另验证大文件按需读取，以及禁用 IndexedDB 后正常播放和复用内存缓存。
