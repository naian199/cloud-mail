# Telegram 表情包导入

在聊天输入区打开表情包，粘贴 `https://t.me/addstickers/名称`、`https://t.me/addemoji/名称` 或表情包名称后点击导入。也支持省略 HTTPS 的分享链接和 `tg://addstickers?set=名称` 应用链接。

## 完整导入

管理员可在“系统设置”的 Telegram 机器人设置中填写有效的机器人 Token。Token 留在服务端，不应发送到聊天、浏览器或代码仓库。可以通过 Telegram 的 @BotFather 创建机器人并获取 Token。导入走官方 `getStickerSet` / `getFile`，支持 WebP、TGS 和 WebM。导入不要求用户绑定个人 Telegram 账户。

## 无机器人备用方式

站点未配置机器人，或机器人 API 暂时不可用时，尝试读取 Telegram 公开表情包页面中的静态预览。界面明确标注为部分静态预览，数量和可用性取决于 Telegram 页面提供的内容；不能把它当成完整动态表情包。页面没有可读预览时会提示配置机器人或上传本地文件。

仅从固定 Telegram 页面和允许的官方 CDN 图片地址读取内容，拒绝第三方地址、跳转、非图片内容与超过 1 MB 的单张文件。机器人 Token 不会发送给公开页面或 CDN。包清单按 Token 指纹区分缓存，配置变化后不复用旧机器人的清单。

## 交互

导入失败保留原有表情包。选择表情只加入当前会话草稿，需手动发送。切换会话、关闭面板或卸载页面后，过期请求不会再把表情加入草稿。也可以使用“上传本地表情”选择 WebP、TGS 或 WebM 文件。

## 验证范围

自动测试覆盖官方 Bot API 成功与失败、公开页面解析、CDN 限制、文件大小与 MIME 校验，以及表情导入、预览和加入草稿的浏览器交互。当前执行环境无法访问 Telegram，外部服务使用固定响应测试；尚未实测截图中具体表情包的在线可用性。
