# 注册异常检查（1.21.1）

邮箱框支持用户名加所选域名，也支持粘贴、自动填充完整邮箱。完整邮箱不再重复附加域名；两端空格会被去除，密码内容保持原样。

普通密码、重复邮箱和注册密钥错误保留为表单提示。只有服务端明确返回人机验证错误时，才会启用额外验证。验证码过期、验证失败或提交后出现其他错误时，已使用的验证 token 会失效并重置原有组件，避免一直重复提交旧 token。

人机验证脚本不可用时显示失败提示和“重新加载验证”。脚本等待限制为 10 秒，组件卸载会取消等待并移除已有验证组件。窄屏使用紧凑尺寸。收到服务端明确验证要求后，仍然必须完成验证才能注册；这些改动不绕过验证，也不修改注册策略。

Turnstile 错误码 110200 会显示“当前域名未获人机验证授权”。此时应检查验证服务是否允许现有邮箱网站域名，不要为此更改网站域名、DNS 或部署路由。其他可用错误码也会显示，便于管理员定位配置或网络问题。

本地验证覆盖真实注册成功、完整邮箱自动填充、重复邮箱，以及模拟的普通校验错误、注册密钥错误、脚本加载失败与恢复、域名授权错误、验证码过期和失效后重试。计数测试使用实际 Drizzle D1 驱动配合本地 SQLite，验证首次插入和后续递增都返回正确计数。验证服务回调使用测试替身，不能据此断言线上 Turnstile 配置已通过验证。
