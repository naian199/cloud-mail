# 会话搜索和共享媒体

在邮件会话中选择联系人，点击标题栏的搜索图标，打开“搜索与会话相册”。

- 搜索当前邮箱下该联系人的完整消息正文和附件名。站内聊天使用去除历史引用后的回复正文；站外邮件还可搜索标题。
- 日期范围按浏览器本地时区的自然日计算，包含结束日，服务端转换为 UTC 比较。
- 图片、文件、链接分类沿用当前搜索及日期条件。图片可预览，文件经登录鉴权下载，链接只允许无账号密码的 HTTP/HTTPS 地址。
- 每次最多扫描60条记录；如仍有历史内容，可点击“加载更早消息”继续。结果按时间倒序排列，不只搜索已在聊天窗口加载的消息。
- “跳到原消息”加载该消息所在的历史窗口并高亮；查看历史时不自动标记整个会话已读，也不被新消息拉回底部。“回到最新消息”恢复正常实时会话。
- 搜索、媒体、跳转均验证当前用户及邮箱所有权，排除已删除内容。会话删除版本变化时，清空已打开抽屉的结果和私有图片对象 URL，重新查询。管理员查看已删除记录仍使用独立入口。

验证：`mail-explorer.integration.mjs` 覆盖鉴权、较早记录分页、完整正文、日期、媒体、历史窗口及双向删除；`mail-shared-links.test.mjs` 覆盖链接安全规则。浏览器测试涵盖手机搜索、图片预览、文件下载、跳转、返回最新、删除同步及320–1440像素布局。

## 消息删除菜单

手机长按约半秒或桌面右击消息可打开菜单。菜单不依赖在线状态服务是否可用。每条消息均可选择“仅为自己删除”，站内一对一消息还提供“删除消息（双方）”和“清空聊天（双方）”。站外邮件、自发邮件不能删除他人的副本。

删除采用保留原文的归档方式。普通用户的会话、搜索、相册、消息及私有附件接口不再返回其已删除的记录，管理员仍可在“全部邮件 → 已删除”查看原始消息和附件。仅为自己删除会保留对方副本；导入的旧版好友消息也按用户隐藏，避免从旧接口重新出现。
