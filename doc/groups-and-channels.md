# 群组、频道与语音输入

侧栏的「群组与频道」支持创建站内群聊或频道。创建者和管理员通过唯一用户名邀请成员；邀请未接受前，对方只能看到邀请名称，不能读取成员列表或消息。接受后可以查看历史消息。

- 群聊：所有已加入成员均可发送文字消息。
- 频道：只有创建者和管理员可以发布，普通成员只读。
- 创建者可以设置管理员、修改名称、邀请和移除成员；管理员可以改名、邀请和移除普通成员。
- 普通成员和管理员可以退出；创建者可经确认后永久删除群组或频道及全部消息。
- 首版支持文字消息和语音转文字，单条上限 20,000 字符。每人最多创建 20 个群组或频道，最多持有 200 个成员身份（包含邀请）；每个群组或频道最多 100 人（包含创建者和邀请）。

输入栏的麦克风按钮调用浏览器的 SpeechRecognition。首次使用会说明音频可能由浏览器发送至其语音服务商，并由浏览器请求麦克风权限。识别结果只进入草稿，不自动发送；切换会话、开始发送、离开页面或切到后台时会停止识别。不支持该 API 的浏览器可以使用系统键盘的语音输入。网页语音输入需要安全上下文及浏览器、系统权限。

群组和频道不发送站外邮件。消息存放在 D1，复用现有的每用户 WebSocket 刷新通知；通知只含刷新信号，消息读取重新验证成员权限。通知协调器每批处理 40 人，避免单次调用超过 Free 计划的子请求预算；客户端另有定期重新同步。发送重试使用同一个 clientId 去重。

## 开发验证

数据库升级由 `ensureMailChat` / `migrateMailChat` 自动完成，新增群组、成员和消息表，沿用 `CHAT_NOTIFICATIONS` 绑定，无需增加新的密钥。

在已初始化的本地 Worker 上运行：

```sh
node --test mail-worker/test/rooms.integration.mjs
node --test mail-worker/test/room-notifications.test.mjs
```

集成检查创建独立测试账号，覆盖邀请、群聊和频道权限、移除和退出、消息重试、分页、未读标记、跨群组隔离、实时通知和创建数量限制。它仅允许 localhost 目标。
