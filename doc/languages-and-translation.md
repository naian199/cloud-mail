# 界面语言与聊天内 Google 翻译

## 界面语言

提供简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、巴西葡萄牙语、俄语、阿拉伯语、印地语、印度尼西亚语、越南语、泰语、土耳其语、意大利语、荷兰语、乌克兰语及马来语。

登录页、个人设置及右上角用户菜单均可选择语言，使用原生语言名称并支持搜索。语言包和 Element Plus 地区包按需加载；切换无需刷新，不重建当前会话及草稿。账号保存的选择优先于本机选择和浏览器语言列表，没有匹配项时使用英语。日期、数字及文件大小采用地区格式，语言不修改时间戳或设备时区。

阿拉伯语启用 RTL；消息收发位置保持一致，邮箱地址与混合文本分别隔离。邮件、主题、昵称、简介、聊天正文等用户内容不随界面语言自动翻译。

新增18种语言为机器翻译初稿，尚未经母语人工校对；请重点校对管理操作、计费及删除提示。每种语言目前568个词条，含服务端错误提示。`shared/interface-translation-status.json`记录校对状态。公共界面词条已作为静态资源写入仓库，运行时切换语言不调用外部翻译服务。

维护词条后运行：

```sh
node scripts/check-locales.mjs
node --test mail-worker/test/interface-catalogs.test.mjs
```

后一个命令需要已安装前端依赖。检查缺失/多余词条、变量、删除确认口令及消息语法；不能用复制英语冒充完成翻译。新的界面语言须在`shared/languages.json`注册，并为前端提供对应 JSON 及 Element Plus 地区加载器。

## Google 翻译配置

管理员进入“系统设置 → Google 翻译”，在 Google Cloud 项目启用 **Cloud Translation API（Basic v2）**，配置计费，并为专用 API 密钥设置 API 限制。将密钥填写到后台，设置额度并启用。不要使用 Google OAuth 客户端密钥，也不要将 API 密钥写入前端或聊天。

密钥保存在现有 Cloudflare KV 中，仅具有`setting:set`权限的用户能修改。读取配置只返回是否已配置及额度，不返回密钥。留空保留已有密钥；勾选删除可清除。默认关闭，没有真实密钥时不会自动调用 Google。

默认每用户每日20次请求，全站每日50000字符，每用户每分钟最多10次；按 UTC 午夜重置。全站及个人额度在同一个 Durable Object 事务中校验，超过额度时不会调用 Google。已通过额度检查但供应商失败的请求仍计入本站请求次数；Google实际账单由Google计费规则及控制台配额决定。

## 使用与数据范围

消息下方点击“Google 翻译”，选择20种目标语言之一，确认发送正文给 Google 后点击翻译。原文保留，译文在同条消息下显示，可以收起；同一消息同一目标语言的结果在当前页面内存中复用。默认不自动翻译。也可在会话列表开启“自动翻译”，选择目标语言并一次确认数据范围；此后只对进入屏幕可视区域的收到消息自动翻译，包含新到消息，保留原文。不会自动翻译自己发出的消息或后台、屏幕外的消息。开关和目标语言保存在当前浏览器，随时可关闭。请求串行排队，每次至少间隔6.5秒；额度耗尽、服务停用或密钥被拒绝时自动关闭开关，避免反复失败。平台统一配置 Google 服务，普通用户无需提供密钥。

站内聊天只翻译本条回复正文，移除历史引用和签名；站外邮件翻译纯文本正文。每次最多5000个 Unicode 字符，超出时显示截断提示。不发送头像、用户资料、图片或附件。翻译结果使用文本渲染，不执行其中的 HTML。

服务端验证登录状态、邮箱归属、消息是否仍可访问及目标语言。只向`https://translation.googleapis.com/language/translate/v2`发送所选正文，API 密钥使用请求头，消息和密钥不会出现在请求 URL 中。请求15秒超时。未配置、额度用尽、密钥被拒绝及供应商失败均显示可本地化错误。

真实 Google 返回结果需在管理员配置有效密钥后验证；无密钥时仅验证接口权限、配置、额度、供应商模拟响应及界面行为，不声称已完成真实翻译调用。
