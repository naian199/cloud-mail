# 独立维护与外部依赖

## 清理范围

| 位置 | 处理 |
| --- | --- |
| 系统设置 | 删除原项目发布接口、更新红点、失败重试；关于页面使用独立版本和本仓库入口 |
| 登录页 | 仓库链接使用 `shared/project-info.mjs` 的自有地址，继续尊重入口显示开关 |
| 远程开发 | 默认 API 使用现有自有站点，不连接其他项目的演示环境 |
| README 和文档 | 删除原项目发布徽章、排名、演示、社群和捐助链接，提供本仓库文档 |
| 文档图片 | 删除旧演示截图、旧文档标识和捐助图片 |
| 部署 | 保留当前仓库的工作流，增加项目身份检查；没有原项目同步或合并任务 |
| 法律声明 | 原始 `LICENSE`、来源说明及第三方许可文件保留 |

没有数据库迁移或业务数据清理；不改用户、邮件、附件、密钥、域名或资源绑定。Git 历史和 GitHub 的历史来源信息不通过代码更新重写；GitHub 如仍显示 fork 关系，它本身不会同步代码。

## 仍然使用的服务

| 服务 | 用途与启用条件 |
| --- | --- |
| Cloudflare Workers、D1、KV、Durable Objects | 网站运行、业务存储、缓存和实时消息 |
| R2 或配置的 S3 兼容存储 | 附件；由现有站点配置决定 |
| Cloudflare Email Routing / 发件服务、Resend | 邮件接收与对外投递；沿用现有域名和服务配置 |
| Turnstile | 注册/验证等配置的验证流程；当前页面仍加载 Cloudflare 官方脚本 |
| Cloudflare Workers AI | 配置后用于邮件验证码识别等功能 |
| Google Cloud Translation | 配置密钥且用户授权后翻译；优先尝试支持的浏览器本地翻译能力 |
| Google 网站图标服务 | 为站外邮件域名获取网站标识，后端代理并缓存；不是发件人身份验证 |
| Telegram Bot API | 配置后导入表情包或转发邮件通知，不是项目社群入口 |
| GitHub、Google、Linux DO OAuth | 只在配置相应登录方式后使用，与版本检查无关 |
| Iconify 图标服务 | 部分旧界面的图标仍由图标组件按需加载；核心聊天控件已打包 |
| FFmpeg WebAssembly | 视频兼容播放在本机处理；固定版本引擎从本站按需加载，没有额外第三方转码上传 |
| 邮件正文中的外部图片、用户配置的 Webhook/转发服务 | 随邮件内容或管理员现有设置使用，不属于固定项目更新接口 |
| GitHub Actions、npm/pnpm 及依赖分发服务 | 构建和部署本仓库代码，不是网页运行时的更新服务 |

独立维护解除的是原项目的产品入口、默认后端和更新检查，不是移除上述正常业务功能所需的供应商。新增依赖或更新锁文件应继续评审其用途和许可。
